**Project:** KeyForge, a fictitious mechanical keyboard storefront.

**GitHub repository:** REPLACE_REPOSITORY_URL

**GitHub Wiki:** REPLACE_WIKI_URL

The application is a client-only React SPA with 25 keyboards loaded from products.json, reusable ProductList/ProductCard/Cart/CartItem components, shared useState cart data, product-option and quantity validation, and validated Account/Create Account forms. Bootstrap 5 provides responsive grid, navbar styling, utility classes, forms, buttons, and alerts; custom CSS defines the store's appearance. React state opens and closes the mobile navbar. No Node.js/Express backend or database is used.

**Resources and disclosure:** No downloaded storefront template was used. I used React, Bootstrap 5, and Vite as documented in the Wiki. ChatGPT/Codex assisted with the component code, fictional product data, original SVG illustrations, custom styling, validation logic, verification, and documentation.
